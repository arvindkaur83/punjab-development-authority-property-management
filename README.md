# punjab-development-authority-property-management
Punjab Development Authority Property Management &amp; Analytics System


## Authorities Covered

This project models property-management workflows across six
regional development authorities in Punjab:

| Code | Authority |
|------|-----------|
| GMADA | Greater Mohali Area Development Authority |
| GLADA | Greater Ludhiana Area Development Authority |
| JDA | Jalandhar Development Authority |
| PDA | Patiala Development Authority |
| ADA | Amritsar Development Authority |
| BDA | Bathinda Development Authority |

The project uses synthetic data designed for portfolio,
analytics, machine learning and RAG experimentation.
It does not contain confidential government or citizen data.
